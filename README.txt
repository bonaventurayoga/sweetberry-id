SWEETY BERRY - HTML + CSS + JAVASCRIPT

Tidak membutuhkan Next.js, React, Node.js, atau npm.

CARA PAKAI:
1. Ekstrak ZIP.
2. Buka index.html untuk katalog.
3. Buka admin.html untuk mengelola produk.
4. Login admin:
   Username: admin
   Password: sweety123

FITUR:
- Tambah, edit, hapus produk
- Upload gambar dari HP/PC
- Aktif/nonaktif produk
- Pencarian dan kategori
- WhatsApp order
- Pengaturan toko
- Responsive HP/tablet/PC

CATATAN PENTING:
Versi ini menyimpan data di localStorage browser. Jadi data hanya berada pada perangkat/browser yang digunakan. Jika mitra mengubah katalog di HP, pelanggan di perangkat lain belum otomatis melihat perubahan. Untuk versi online multi-perangkat, penyimpanan perlu dipindahkan ke database seperti Supabase.
